# Карта света

Локальный прототип. В интернет не выложен. Комментарии из чатов пишутся в `data/live-reports.json` на этом компьютере и красят улицу на 6 часов.

Код: `/Users/lerk/home-mac/karta-sveta`. Карточка: `Lerk/продукты/Карта света.md` в vault.

## Зачем

Показать по улицам Донецка, где свет есть и где его нет. Подписи карты на русском. Киевский район при открытии страницы красится сам по кругу графика от 9 октября и текущему часу. Комментарий с названием улицы и словами про свет красит эту улицу целиком, в любом районе, и перекрывает график на 6 часов.

## Как открыть

Из папки проекта:

```bash
python3 server.py
```

Дальше `http://127.0.0.1:8765/`. Файл с диска напрямую не открывать: браузер не отдаст `data/streets.geojson`. Сервер `server.py` и отдаёт страницу, и принимает комментарии.

Подложка — векторные тайлы OpenFreeMap, подписи переключаются на `name:ru`. Линии улиц лежат локально, имена тоже русские (`name:ru`, иначе перевод с украинского). График очередей: `data/kyiv-queues.json`.

## Что делает страница

- Поиск улицы и нажатие на линию выбирают участок.
- Поле «Комментарий из чата» принимает текст из группы. Если в нём есть улица и «свет есть» или «света нет», красится вся эта улица на 6 часов. Имя автора не сохраняется, в поле группы пишется название чата.
- «Свет есть» и «Света нет» делают то же для выбранной улицы.
- Страница сама забирает новые записи каждые 20 секунд.
- Серый участок — нет ни свежего комментария, ни графика. Фраза «в таком-то районе» улицы не красит.
- «Скачать отметки» пишет JSON. «Загрузить отметки» читает его обратно.
- Полоска сверху и блок «Откуда данные» берут текст из `data/sources.json`. График районов улицы не красит.

## Как обновить линии улиц

Overpass, граница Донецка в OSM (отношение 1413957, область 3601413957):

```bash
curl -fsSL --max-time 200 -A "karta-sveta-local/0.1" -o /tmp/donetsk-streets.json \
  --data-urlencode 'data=[out:json][timeout:160];area(3601413957)->.a;way["highway"~"^(trunk|primary|secondary|tertiary|residential|living_street|unclassified)$"]["name"](area.a);out geom;' \
  "https://overpass-api.de/api/interpreter"
python3 scripts/build_streets.py /tmp/donetsk-streets.json
```

Скрипт режет длинные линии кусками около 500 метров и склеивает соседние короткие обрывки, если их концы ближе 40 метров и вместе они не длиннее 500 метров. Пишет `data/streets.geojson` и `data/streets-index.json`.

## Чего прототип не делает

Чужая группа сама сюда не пишет, пока сообщение не переслали в поле на странице или не отправили на `POST /api/comments` телом `{"text":"на Артёма нет света","source":"Киевский чат"}`. Логин не нужен. Имя, телефон и квартира не хранятся. Выкладки наружу нет, пока её отдельно не попросят.

Бот Telegram не подключён: для него нужны название групп и токен. Пока текст из группы вставляется в поле или приходит на этот адрес.
