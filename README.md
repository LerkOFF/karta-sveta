# Карта света

Карта улиц Донецка: где есть свет, где нет и насколько этому можно верить. Живая версия: https://lerk.tech/svet/

Статус улицы собирается из отметок людей (чаты, кнопки на карте) и графика отключений. У каждой отметки есть возраст и уверенность: чем старше и спорнее, тем блёклее цвет улицы. Зависимостей нет, только Python 3:

```bash
python3 server.py
```

Как это устроено, API, приём из чатов Telegram и выкладка: [docs/README.md](docs/README.md).
